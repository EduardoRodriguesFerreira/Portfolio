# Portfolio Freelancer - Eduardo Rodrigues Ferreira

Portfólio estático profissional para divulgação de serviços freelancer em desenvolvimento web, landing pages, sistemas administrativos, dashboards, automações, APIs e análise de dados.

## Stack

- HTML5 semântico
- CSS3 responsivo com tema claro/escuro
- JavaScript puro
- Font Awesome para ícones
- Google Fonts para tipografia

## Projetos demonstrativos principais

- Landing Page Clínica
- Landing Page Consultoria
- Dashboard Financeiro
- Dashboard Comercial
- Sistema Administrativo
- Sistema de Propostas e Contratos
- CRM de Atendimento
- API e Integrações

## Personalização rápida

- Número do WhatsApp: altere a constante `WHATSAPP_NUMBER` em `script.js`.
- Foto: substitua `img/foto.jpeg`.
- Currículo: substitua `Curriculo_Eduardo_Rodrigues.pdf`.

## Como abrir

Abra `index.html` no navegador ou publique a pasta no GitHub Pages, Vercel, Netlify ou hospedagem estática.
